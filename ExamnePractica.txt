Diseño de Base de Datos
Una universidad necesita almacenar información de:
Estudiantes
Carreras
Materias
Profesores
Inscripciones
Se solicita:
Diseñar el modelo relacional.
Crear las tablas mediante SQL.
Definir:
Claves primarias.
Claves foráneas.
Restricciones necesarias.
Agregar al menos una relación de uno a muchos y una de muchos a muchos.


Corrección de Script SQL
El siguiente script contiene
CREATE DATABASE Universidad

USE Universidad;

CREATE TABLE Carrera(
idCarrera INT PRIMARY,
nombre VARCHAR(100)
);

CREATE TABLE Estudiantes(
idAlumno INT PRIMARY KEY,
nombre VARCHAR(100),
apellido VARCHAR(100),
edad VARCHAR(3),
idCarrera VARCHAR(20),
FOREIGN KEY idCarrera REFERENCES Carrera(idCarrera)
);

CREATE TABLE Profesor(
idProfesor INT,
nombre VARCHAR(100),
especialidad TEXT,
PRIMARY idProfesor
);

CREATE TABLE Materias(
idMateria INT PRIMARY KEY,
nombre VARCHAR(100),
creditos INT,
idProfesor INTEGER,
FOREIGN KEY(idProfesor)
REFERENCES Profesores(idProfesor)
);

CREATE TABLE Inscripciones(
idInscripcion INT PRIMARY KEY,
idAlumno INT,
idMateria INT,
fecha DATE,
FOREIGN KEY(idAlumno)
REFERENCES Estudiante(idAlumno),
FOREIGN KEY(idMateria)
REFERENCES Materias(idMateria)
)
